## 1. Product summary

**Name:** The Wedding Dreams  **Tagline:** *A complete event solution*
**Type:** Ultra-luxury wedding planning and venue/vendor discovery marketplace (concierge-led, not self-serve booking).
**Primary market:** India (launch focus: Delhi NCR, Jaipur, Udaipur, Goa), English UI, Hindi/Sanskrit accent words only as small captions.
**Core promise:** One concierge team coordinates the client, the venue and every vendor, so the couple has one conversation instead of twenty.

### 1.1 How the business works
1. Couples browse curated venues and verified vendors with 4K video and 4K galleries.
2. A couple submits a **Concierge Enquiry** (never contacts a vendor directly).
3. The lead goes to The Wedding Dreams concierge team only.
4. The concierge shortlists, arranges visits, collects quotes, negotiates, and coordinates until booking.
5. Venue and vendor owners join through **Become a Partner**; every application is `pending_verification` until an Admin approves.

### 1.2 Brand context (from the logo)
A cream-ivory ceremonial elephant carrying a Royal Crimson (#9E192D) and gold chhatri, flanked by Lotus Pink (#E05286) lotuses, over an Antique Gold serif wordmark and a crimson italic tagline. Logo file: `logo-full-bg-rem.png` (transparent PNG). Never redraw or recolour it.

## 2. Goals and non-goals

### Goals
- G1. Make a bride, groom or family feel "this is handled" within 10 seconds of landing.
- G2. Generate high-quality, concierge-routed leads (Concierge Enquiry submissions).
- G3. Grow a verified supply of venues and vendors through the partner flow.
- G4. Let non-technical admins run the whole site (hero videos, banners, listings, approvals) without developers.
- G5. Protect all client and partner private data (zero leakage of contacts, pricing, docs, unapproved submissions).
- G6. Deliver Awwwards-level motion and 4K media while staying at 60fps and good Core Web Vitals.

### Non-goals (v1)
- Online payments, instant booking, calendar-level availability, or marketplace checkout.
- Direct client-to-vendor messaging.
- Native mobile apps (responsive web only).
- Multi-language UI (English only in v1; architecture must not block i18n).
- Dark mode (explicitly forbidden: see DESIGN_SYSTEM.md).

## 3. Personas

| Persona | Needs | Key flows |
|---|---|---|

| **Venue owner / manager** | Qualified leads, a showcase worthy of the property | Become a Partner, track application status by reference ID |
| **Vendor** (decorator, photographer, couture, caterer, entertainer) | Visibility, verified badge, intros from the concierge | Become a Partner |

| **Admin** | Control, verification, security | Approvals, roles, audit log |

## 4. Functional requirements

Priority: **P0** = launch blocker, **P1** = launch target, **P2** = post-launch.

### 4.1 Global shell
- FR-1 (P0) Glassmorphic sticky header: logo on plinth, nav (Venues, Vendors, Real Weddings, Journal, Our Concierge), ghost "Concierge Enquiry", solid crimson "Become a Partner". Hides on scroll down, returns on scroll up.
- FR-2 (P0) Mega-menus for Venues (By Setting / By City / By Guest Count + featured image) and Vendors (6 categories + featured image). Keyboard and touch accessible.
- FR-3 (P0) Mobile full-screen ivory menu sheet with both CTAs pinned.
- FR-4 (P0) Luxury editorial footer: newsletter, 5 link columns, social strip, cropped brand signature, legal row.

### 4.2 Home page
- FR-5 (P0) **Hero "Processional Window":** 100svh inset frame with arch-curved corner, 4K video carousel driven by `cms_hero_slides`, crossfade and arch-mask transitions, chapter switcher (Sangeet, Mehendi, Pheras, Reception, Destination, Pre-Wedding) with progress ring, muted-by-default ambient sound toggle, pause/play, headline overlay on a light ivory gradient, Quick Search Pill (Venue/Vendor, City, Date, Guests).
- FR-6 (P0) **Signature Decor & Curated Experiences:** pinned horizontal asymmetrical gallery (desktop), snap carousel (mobile), followed by 4 experience cards.
- FR-7 (P0) **Dual-Discovery Hub:** Venues | Vendors toggle, sticky filter chips, cards with poster + hover 4K preview, Verified badge, capacity, location, setting, tier diamonds, "Request Concierge Quote".
- FR-8 (P0) **How It Works ("The Procession"):** pinned 5-step timeline, path drawing, elephant marker, lotus nodes; vertical on mobile.
- FR-9 (P0) **Become a Partner showcase** with the 5-step application drawer.
- FR-10 (P1) Real Weddings teaser, Journal teaser, testimonials band.

### 4.3 Listings
- FR-11 (P0) Venues index and Vendors index with server-side filtering, sorting, pagination, and shareable URLs.
- FR-12 (P0) Venue and Vendor detail pages: 4K hero video, sticky sub-nav, masonry gallery with lightbox, at-a-glance sidebar, sticky quote card. **No phone, email, WhatsApp or exact price anywhere.**
- FR-13 (P1) Save/favourite (local only in v1; synced later).
- FR-14 (P1) Real Weddings gallery pages linking to the venues/vendors used.

### 4.4 Leads
- FR-15 (P0) Concierge Enquiry drawer (3 steps: Date & City, Guests & Budget tier, Contact). Pre-fills venue/vendor when opened from a card.
- FR-16 (P0) CAPTCHA (Turnstile), honeypot, rate limiting, consent checkbox, reference code returned.
- FR-17 (P0) Confirmation email to the client (no partner details) and notification to the concierge team.

### 4.5 Partner onboarding
- FR-18 (P0) 5-step drawer: Who you are; Brand details; Portfolio (up to 5 4K video links + images); Pricing tier & capacity; Verification & contact (GST, docs, CAPTCHA).
- FR-19 (P0) Submission creates `partner_applications` row with `pending_verification`, returns a reference ID; applicant receives an email.
- FR-20 (P1) Applicant can check status with reference ID + email (no account).
- FR-21 (P0) Nothing from an application is public until Admin approves **and** an Editor publishes the listing.

### 4.6 Admin CMS (`/admin`)
- FR-22 (P0) Hero Video Manager: upload 4K, processing status, reorder, schedule, live preview, publish/revert.
- FR-23 (P0) Partner Verification Queue: filter, review drawer, secure docs viewer, checklist, Approve / Request info / Reject, templated emails.
- FR-24 (P0) Venue and Vendor CRUD with 4K media uploader, tabs (Basics, Capacity & Tier, Media, Amenities, Private Details, SEO, Preview).
- FR-25 (P0) Banners manager.
- FR-26 (P0) Leads kanban + table with notes and assignment.
- FR-27 (P0) Team & Roles, 2FA enforcement, audit log viewer.
- FR-28 (P1) Media library with replace-in-place and usage protection.

## 5. Non-functional requirements

| Area | Requirement |
|---|---|
| Performance | LCP < 2.0s on 4G mid-tier phone; CLS < 0.05; INP < 200ms; 60fps scroll on mid laptop; initial JS < 220KB gzip |
| Media | 4K masters stored privately; HLS adaptive streaming; hero + 1 concurrent decoders max 2; posters first |
| Accessibility | WCAG 2.2 AA; reduced-motion respected; keyboard-complete; captions/descriptions for hero slides; pause control for any autoplay |
| Security | RLS everywhere, no private data in public DOM/API, 2FA for staff, audit log (see SECURITY.md) |
| SEO | SSR/ISR pages, structured data (Organization, LocalBusiness/EventVenue), sitemap, OG images |
| Browser support | Last 2 versions of Chrome, Safari, Edge, Firefox; iOS 16+; Android 10+ |
| Privacy | India DPDP Act aligned; consent timestamps; deletion request flow; IPs hashed |
| Reliability | 99.9% target; daily encrypted backups; tested restore |

## 6. Success metrics
- Enquiry conversion rate (visits to submitted enquiry) target ≥ 2.5%.
- Partner application completion rate ≥ 45% of drawer starts.
- Median concierge first-response time < 24h (tracked in CMS).
- Verified partner count by city; 4K media coverage of published listings ≥ 90%.
- Lighthouse Performance ≥ 90 mobile on home page (with hero poster path).

## 7. Content model (public)
Venue, Vendor, Media (4K), Hero Slide, Banner, Real Wedding, Journal article, Experience (curated collection), City, Category.
